# نبرد شرکت — سوات vs تروریست

بازی **سه‌بعدی از نمای بالا** ساخته‌شده با **Three.js**. درگیری بین **تیم سوات** و **تیم تروریست** داخل ساختمان مرکزی یک شرکت بزرگ رخ می‌دهد و **برق شرکت قطع است**؛ فقط چراغ‌قوه‌ها و چراغ‌های اضطراری روشنایی می‌دهند.

## مدل‌های سه‌بعدی (GLB واقعی)

همه‌ی مدل‌ها از پک‌های رایگان **Quaternius** با لایسنس **CC0**، دانلودشده از گیت‌هاب:
[github.com/trebeljahr/quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase)

|---|---|---|

### تغییر ظاهر کاراکترها
- هر کاراکتر با **رنگ تیمی** (سوات آبی، تروریست قرمز) نورانی/رنگ‌آمیزی می‌شود.
- **سلاح GLB** به استخوان دست راست (`HandR`) هر کاراکتر وصل می‌شود.
- انیمیشن‌ها با نگاشت مستقیم نام استخوان‌ها (بدون ریتارگت ناقص) روی ریگ کاراکترهای تیم سوار می‌شوند — تست شده: ۱۷ استخوان در حرکت شرکت می‌کنند.

## تاریکی مطلق و چراغ‌قوه

- **هیچ نور محیطی‌ای وجود ندارد** (نه خورشید، نه نور آسمان). شرکت در تاریکی کامل است.
- هر کاراکتر یک **چراغ‌قوه نصب‌شده روی اسلحه** دارد که فقط **مخروطی جلوی لوله‌ی اسلحه** را روشن می‌کند (زاویه ۳۰ درجه، برد ۲۶ متر).
- **کلیک راست ماوس** یا کلید `E` چراغ‌قوه‌ی خودت را روشن/خاموش می‌کند.
- **کسی کسی را نمی‌بیند** مگر:
  1. در مخروط چراغ‌قوه‌ی او باشد،
  2. یا فاصله کمتر از ۲.۶ متر باشد (صدای نفس و قدم).
- برچسب نام و نوار سلامتی دشمن و هم‌تیمی‌ها **فقط وقتی چراغ‌قوه روشنشان کرده باشد** ظاهر می‌شود — وگرنه کاملاً پنهان‌اند.
- مینی‌مپ هم در تاریکی چیزی نشان نمی‌دهد؛ فقط چیزهایی که داخل مخروط نور تو هستند (به‌علاوه مخروط نور خودت) دیده می‌شوند.
- تروریست‌ها اکثر وقت‌ها چراغ‌قوه‌شان خاموش است و فقط گاهی برای چند ثانیه روشن می‌کنند — از همین لحظه‌ها می‌توانی موقعیتشان را ببینی.

## سلاح‌های بازیکن

| کلید | سلاح | مشخصات |
|---|---|---|
| `۱` | **اسلحه سنگین — شاتگان** | ۸ ساچمه در هر شلیک، آسیب ۲۰ در هر ساچمه با افت فاصله، برد ۱۳ متر، خشاب ۶ |
| `۲` | **کلت — هفت‌تیر** | تک‌گلوله، آسیب ۴۶، برد ۲۰ متر، خشاب ۶، دقت بالا |
| `۳` | **چاقو** | ضربه در کمان ۲ متری، آسیب ۸۵، بی‌صدا (چراغ‌قوه لازم نیست) |

سلاح‌ها با کلیک روی دکمه‌های HUD هم عوض می‌شوند. `Shift + غلتک ماوس` هم سلاح بعدی/قبلی را می‌آورد.

## امکانات بازی

- **نمای از بالا** با دوربین دنبال‌کننده و زوم با غلتک ماوس
- **مپ شرکت** ۶۰×۴۴ متر با ۶ اتاق (مدیریت، جلسات، سرور، آزمایشگاه، امنیت، بایگانی)، راهرو مرکزی و هسته آسانسور
- **برق قطع**: تاریکی، مه، چراغ‌های اضطراری قرمز چشمک‌زن و چند لامپ باتری‌خور کم‌سو
- **چراغ‌قوه** برای بازیکن (کلید `E` خاموش/روشن) — مخروط دید روی مینی‌مپ هم رسم می‌شود
- **نارنجک** (`Q`): انفجار منطقه‌ای با شعاع آسیب، ذرات، لرزش دوربین — آسیب به هم‌تیمی کم‌تر
- **دودزا** (`F`): ابر دود ۱۶ ثانیه‌ای که دقت تیر هر دو تیم را به‌شدت کم می‌کند
- **تیم سوات** (بازیکن + ۴ هم‌تیمی NPC) و **تیم تروریست** (۵ نفر) هر کدام با ترکیب سلاح و نقش متفاوت (مهاجم، پشتیبان، تک‌تیرانداز، پزشک، خرابکار، نفربر)
- **هوش مصنوعی**: خط دید، تعقیب، دور زدن مانع، حفظ فاصله مناسب نقش، دقت وابسته به فاصله/دود/حرکت
- **HUD کامل**: نوار جان و زره، شمارنده خشاب، وضعیت دو تیم (نفرات زنده و کشته‌ها)، مینی‌مپ زنده، تخته امتیاز (`Tab`)
- خشاب خالی → پر کردن مجدد با `R`؛ تک‌تیرانداز بعد از هر گلوله خشاب می‌زند
- **گالری مدل‌ها** (دکمه 🎨): چرخاندن هر مدل GLB روی سکو با ماوس

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده (پیش‌فرض http://localhost:5173) را باز کنید.

## کنترل‌ها

| کلید / دکمه | کار |
|---|---|
| `W A S D` / کلیدهای جهت | حرکت |
| ماوس | نشانه‌گیری |
| کلیک چپ | شلیک |
| `R` | پر کردن خشاب |
| `Q` | پرتاب نارنجک |
| `F` | پرتاب دودزا |
| **کلیک راست** | روشن/خاموش کردن چراغ‌قوه (نصب‌شده روی اسلحه) |
| `E` | روشن/خاموش کردن چراغ‌قوه |
| `۱` `۲` `۳` | شاتگان سنگین / کلت / چاقو |
| `Tab` | تخته امتیاز |
| `Esc` | بستن پنل‌ها |
| غلتک ماوس | زوم دوربین |

روی موبایل: جوی‌استیک برای حرکت، دکمه 🔥 برای شلیک، دکمه‌های نارنجک و دودزا.
