# روستای سه‌بعدی — بازی از نمای بالا (Top-Down 3D)

بازی سه‌بعدی با نمای از بالا، ساخته‌شده با **Three.js**. بازیکن در یک روستای کم‌پلی‌گان حرکت می‌کند، با دشمن‌ها می‌جنگد و اسلحه‌های مختلف برمی‌دارد.

## مدل‌های سه‌بعدی (از سایت‌های مدل)

۵۶ مدل رایگان با لایسنس **CC0** از پک‌های **Quaternius**، دانلودشده از گیت‌هاب:

- منبع: [github.com/trebeljahr/quaternius-showcase](https://github.com/trebeljahr/quaternius-showcase) (نمایشگاه رسمی مدل‌های Quaternius)
- دسته‌بندی در `public/models/`:
  - `weapons/` — ۲۲ اسلحه: شمشیر، تبر، کمان، نیزه، خنجر، چکش، کاتانا، ۶ تفنگ AR، تپانچه، مسلسل دستی، تک‌تیرانداز، زنبورک، نارنجک، سپر
  - `ground/` — زمین و طبیعت: درخت (کاج، توس، معمولی)، سنگ، بوته، علف، گل، گندم، کاکتوس، کنده، مسیر خاکی
  - `props/` — وسایل و ساختمان‌ها: خانه، ساختمان، چاه، آتش، غرفه بازار، گاری، کاه، جعبه، بشکه، حصار
  - `characters/` — کاراکترها: شوالیه (بازیکن)، ماجراجو، سرباز SWAT (دشمن)
  - `animals/` — حیوانات: گاو، اسب، گرگ، روباه

## اجرا

```bash
npm install
npm run dev
```

سپس آدرس نمایش‌داده‌شده (معمولاً http://localhost:5173) را باز کنید.

## کنترل‌ها

| کلید | کار |
|---|---|
| `W A S D` | حرکت |
| ماوس | نشانه‌گیری |
| کلیک چپ | حمله / شلیک |
| `E` | برداشتن اسلحه روی زمین |
| غلتک ماوس | زوم دوربین |
| `Esc` | بستن گالری مدل‌ها |

روی موبایل: جوی‌استیک سمت راست برای حرکت و دکمه ⚔️ برای حمله.

## امکانات

- دوربین از نمای بالا که بازیکن را دنبال می‌کند
- موج‌های دشمن (SWAT، ماجراجو، گرگ) با نوار سلامتی
- ۲۲ اسلحه با مشخصات متفاوت (ضربه‌ای، کمان، تفنگ، نارنجک با انفجار منطقه‌ای)
- حیوانات آزاد که از بازیکن فرار می‌کنند
- نقشه کوچک (مینی‌مپ)، امتیاز، موج و سلامتی
- **گالری مدل‌ها**: دکمه 🎨 برای چرخاندن و دیدن هر ۵۶ مدل به‌صورت جداگانه
